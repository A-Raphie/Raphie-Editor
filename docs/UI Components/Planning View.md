# Planning View

**File**: `src-electron/renderer/src/components/PlanningView.tsx`

Shows scene plan preview after generation. Displays beat count, total duration, and beat type breakdown.

## Features

- Scene plan header (title, beat count, duration)
- Beat breakdown by type (clips, images, motion graphics)
- Loading state with spinner during generation
- Retry indicator for LLM retries
